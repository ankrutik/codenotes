- [[iCloud Calendar on Fedora/Linux]] #fedora
	- Go to [Apple Accounts](https://account.apple.com/)
	- Create an app-specific password
	- On Fedora
		- Settings > Online Accounts > WebDAV
		- `caldav.icloud.com`
		- *Email used for Apple account*
		- *App-specific password*
		- Open Calendar, force sync if it doesn't start syncing
- [[Wireplumber config to not let Bluetooth Speaker Sleep or Disconnect]] #fedora
	- ```
	  sudo mkdir -p ~/.config/wireplumber/wireplumber.conf.d
	  sudo vim ~/.config/wireplumber/wireplumber.conf.d/51-bluez-config.conf
	  monitor.bluez.rules = [
	    {
	      matches = [
	        { node.name = "~bluez_output.*" }
	      ]
	      actions = {
	        update-props = {
	          session.suspend-timeout-seconds = 0
	        }
	      }
	    }
	  ]
	  systemctl --user restart wireplumber pipewire pipewire-pulse
	  wpctl status
	  ```
